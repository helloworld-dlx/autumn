# Autumn Private Monorepo

Private source baseline for the frozen Autumn V0.2 One Autumn release.

- `bridge/pi/`: Pi Bridge source and tests.
- `core/pi/`: OpenClaw plugins and helpers maintained for Autumn.
- `nodes/windows/`: Windows Runner and Bridge source/tests.
- `voice/pwa/`: Portable Voice Bridge and PWA source/tests.
- `deploy/systemd/`: non-sensitive unit templates.
- `docs/`: canonical records and migration boundary.

Production files remain on their current Pi and Windows locations. See [docs/MIGRATION_BOUNDARY.md](docs/MIGRATION_BOUNDARY.md).
