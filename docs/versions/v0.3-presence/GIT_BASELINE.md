# Autumn V0.3-0A — Private Git Baseline

This is a source snapshot boundary following the frozen Autumn V0.2 One Autumn release. It creates no production deployment, service, model, or V0.2 implementation change.

The baseline tracks the reproducible Autumn-maintained code and canonical documentation needed for future work, while excluding secrets, private memory, live OpenClaw state, job state, media, logs, and generated artifacts.
